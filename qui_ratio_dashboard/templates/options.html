Prowlarr

Détection automatique des événements

À l'apparition d'un nouveau torrent, consulte l'historique Prowlarr pour détecter freeleech, silverleech ou double upload.

Vérifiez les paramètres avant de sauver.

Incompatible avec QUI : QUI transmet déjà des totaux groupés sans hash de torrent. Pour qBittorrent, Transmission et Deluge, seuls les torrents ajoutés depuis le dernier intervalle de collecte sont vérifiés. Avec rTorrent, la date d'ajout n'étant pas fiable, Prowlarr est interrogé uniquement lorsqu'un torrent apparaît pour la première fois dans l'application. Dans tous les cas, le grab doit être présent dans l'historique Prowlarr.

Collecte

La collecte automatique est toujours active, même lorsque le dashboard n'est pas ouvert.

La fréquence minimale acceptée est d'une minute. Le changement est appliqué dès la sauvegarde.

Utilise les réglages actuellement sauvegardés.

Sécurité

L'application principale n'intègre pas de connexion utilisateur et conserve les accès aux clients torrent et à Prowlarr. Ne l'exposez pas directement sur Internet : utilisez un réseau privé ou une authentification en amont.

L'authentification Homarr ci-dessus protège uniquement l'iFrame.
